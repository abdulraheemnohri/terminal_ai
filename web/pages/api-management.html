Credential and routing rules

  • Saving a key updates the selected provider's local credential entry; the key is never read back into this page.
  • Provider profiles store model, endpoint, generation parameters, timeout, and failover priority separately for each provider.
  • Use HTTPS for remote custom endpoints. Plain HTTP is accepted only for loopback/local endpoints.
  • A connection test sends a minimal “Reply with OK only” prompt to the provider. It does not change your default model.
  • Chat & Models runs a real test turn only after you explicitly confirm it may enter the active conversation and local archive.
