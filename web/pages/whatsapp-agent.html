WhatsApp Agent API

Dedicated controls for the Meta WhatsApp Agent Platform integration: credentials, polling, health, manual test, and message send.

Important: This is the WhatsApp Agent Platform API, not QR pairing and not the WhatsApp Business Cloud API. V1 supports text only and sends messages to the verified creator identity. Meta's Agent Platform chats are not end-to-end encrypted.

Setup checklist

  1. Open WhatsApp → Settings → Agents and create or open an agent.
  2. Open the agent chat, then Chat info → API key. Copy the Agent API key.
  3. Save the key here, test it, then enable polling.
  4. Send a text message to the agent in WhatsApp to verify the inbound flow.

One active poller should use an agent API key at a time. Do not share or paste API keys into chat messages.
